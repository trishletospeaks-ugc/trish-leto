## How to change things

Everything is generated by `build.py`. **Do not hand-edit the HTML**; edit `build.py` and run:

```bash
python3 build.py            # writes every page, robots.txt, sitemap.xml, site.webmanifest, then audits
python3 build.py --audit    # audit only
```

The header, footer, email, handles, stats, event and video list are each defined once near the top of `build.py`. `assets/css/style.css` and `assets/js/site.js` are hand-edited source files; the build stamps a cache-busting `?v=` hash onto them.

The audit fails the build on: any em dash or en dash in any text file, more or fewer than one `<h1>` per page, a robots meta that does not match `INDEXABLE`, a wrong canonical, JSON-LD that does not parse, an `<img>` without alt or size, a broken internal link, or a missing icon or OG image.

### The two switches

- **`BASE`** (now `https://ogeddiesmith.github.io/trish-leto/`): canonical tags, Open Graph, JSON-LD and the sitemap all come from it. To move to her own domain, change this one line, add a `CNAME` file with the domain, and rebuild.
- **`INDEXABLE`** (now `False`): every page emits `noindex,nofollow` and `robots.txt` disallows everything. Set it to `True` to emit `index,follow` and a `robots.txt` that allows all and lists the sitemap.

Note: crawlers only read `robots.txt` at the root of a host. While the site lives at the `/trish-leto/` project path, the `robots.txt` in this folder is ignored and the per-page noindex meta tag is what keeps it out of search. On her own domain both apply.

### Images

```bash
python3 tools/make_images.py   # crops + WebP from ../photos/ into assets/img/
python3 tools/make_icons.py    # favicons (Pillow) + assets/img/og-image.jpg (headless Chrome from tools/og.html)
```

Sources stay outside this repo in `../photos/`. The crops keep audience heads and the mouse cursor out of the speaking photo, and cut the title line off the summit graphic (the page prints the talk title as text). When Trish sends originals, point `SOURCES` in `tools/make_images.py` at them and re-run; file names stay the same, so no HTML changes are needed.

### Layout check

```bash
python3 -m http.server 8765 --bind 127.0.0.1     # from this folder
node tools/check_layout.mjs ../site-screenshots   # 360, 390, 768, 1280 px
```

It uses real mobile emulation over the Chrome DevTools Protocol, compares `scrollWidth` to the device width, counts `<h1>` tags, reports console errors and failed requests, and saves full-page screenshots. The 404 page shows failed requests locally because its assets point at the live BASE.

## House rules for this site

1. US English. No em dashes or en dashes.
2. Never invent brand clients, testimonials, results, prices or credentials. Products in her TikTok videos are her own content, never presented as clients. Packages are always "custom quote."
3. No day job, age, birthday, family or kids, beyond the "hands only, never faces" rule.
4. Social numbers always say "as of" (`STATS_AS_OF`). Refresh them from her TikTok before launch.
5. No third-party embed on page load. TikTok cards are plain links; TikTok's official player loads only when someone presses Play.
